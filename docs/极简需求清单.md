# 极简需求清单

> 从 [需求文档](需求文档.md)、[路线图](路线图.md) 蒸馏的一页清单:每条一行,只留"要什么 + 做没做"。
> 状态源:[STATUS](STATUS.md)。✅ 已交付 · ⬜ 未做 · ✖ 明确不做。

**一句话定位**:个人自用记账 Web 应用,核心是 OCR 截图批量入账 + 基金跨期追踪;数据归自己(自托管/单机)。

## 记账(P0)

- ✅ 手动记一笔:金额键盘 + 分类宫格 + 备注,2 次点击可达
- ✅ 编辑/删除:底部编辑面板,删除需确认
- ✅ 批量修改:多选 → 改分类/账户/日期/删除,一次撤销
- ✅ OCR 批量导入:识别 → 待确认清单(去重、存疑标黄、人工确认才入账)→ 商户映射越用越准
- ✅ 流水首页:月度汇总、按日分组、月份切换
- ✅ 分类/账户管理:增改删,使用中保护,改名同步历史
- ⬜ 流水搜索/筛选 UI
- ⬜ OCR 原图保留期限设置(占位)

## 基金(P1)

- ✅ 持仓截图 OCR 批量录入(同代码归一、同日覆盖)
- ✅ 跨期追踪:涨跌幅表 + 走势图 + 持有期汇总
- ✅ 投资总览 + 手动记/补录/删除快照

## 分析与守护(P2/P3)

- ✅ 消费分析:环比、6 月趋势、分类结构
- ✅ 预算:分类月度限额、执行进度、超支提醒
- ✅ 周期支出:登记 + 流水候选识别 + 记一笔顺延 + 到期提醒
- ✅ 异常支出检测:近 3 月基线,单笔/分类偏离提醒
- ✅ 净资产总览 + 月度报告
- ⬜ 自动记账、支出预测(推荐功能,后续版本)
- ⬜ 通知推送

## 平台与形态(P4)

- ✅ 登录/注册 + 中央访问守卫(可关闭注册)
- ✅ PWA 加主屏
- ✅ AI 财务问答(只发汇总数据)
- ✅ 单机版(无后端):单 HTML + localStorage,功能对齐,安卓三种打开方式
- ⬜ 离线壳(Service Worker)

## 数据与运维

- ✅ 金额一律整数「分」;SQLite 单文件,备份=拷文件
- ✅ 导出 CSV(流水/基金,防乱码防注入)
- ✅ macOS 家用服务器:一键配置、常驻自启、每日备份、Tailscale 内网
- ✅ CI:GitHub Actions 每次 push/PR 跑 lint + 构建 + 全量测试
- ✅ CD:MacBook 每 10 分钟自动拉取 main 上线,构建失败回滚

## 明确不做 ✖

- 多用户数据隔离 / 社交体系(单用户自用,ADR 0012)
- 云服务托管(数据不上第三方云)
- API Key 进前端(只放服务端环境变量)
