# 单机版(无后端)· 沙盒试用入口

> **完全不需要后端**的记账本版本:自包含单 HTML,双击即可本地打开,数据仅存访问者浏览器 localStorage,不依赖任何服务器。既是免部署的沙盒试用入口,也是可日常使用的单机版。

- **在线入口**(Claude Artifact,仓库所有者账号私有,可从页面分享):
  https://claude.ai/code/artifact/903d0db0-6509-4c29-9fd6-9967280e7bb8
- **源文件**:[`docs/demo/记账本演示.html`](demo/记账本演示.html)(自包含单文件,可直接双击本地打开;保存到手机后离线可用)

## 在安卓手机上使用

单机版在安卓上有三种打开方式,按需选择:

| 方式 | 需要 | 离线可用 | 数据保存 | 适合 |
|------|------|---------|---------|------|
| A. Artifact 链接 | 网络 + claude.ai 登录 | ✗ | ✅(存于该浏览器) | 快速试用 |
| B. 本地文件(file://) | 传一次文件 | ✅ | ✅(见注意事项) | 零安装轻度使用 |
| C. Termux 本地服务 | 装 Termux + Python | ✅ | ✅ 最稳 | 长期主力、可加主屏 |

### 方式 A:直接开在线入口

Chrome 打开顶部的 Artifact 链接 → 菜单 → **添加到主屏幕**。最省事,但需网络与 claude.ai 登录。

### 方式 B:本地文件,零安装

1. 把 `docs/demo/记账本演示.html` 传到手机(微信文件传输/网盘/数据线均可),放到「下载」目录;**建议先重命名为 `ledger.html`**,后面地址好输。
2. Chrome 地址栏输入 `file:///sdcard/Download/ledger.html` 打开。

**注意**:若从某些文件管理器直接点开(地址栏显示 `content://` 开头),浏览器会禁止网页保存数据——此时页面仍可正常使用,但会显示琥珀提示条「当前打开方式无法保存数据」,关闭即丢失。遇到提示条就改用上面的 `file:///` 地址或方式 C。

### 方式 C:Termux 三条命令起本地服务(推荐长期使用)

`localhost` 来源的存储最稳定,还能正常「添加到主屏幕」。只是静态文件服务,**无需 proot/Node**(与整套真实应用的 [Termux 部署](部署-Termux.md)不同,任何手机都跑得动):

```bash
pkg install python
termux-setup-storage        # 首次执行一次,授权访问下载目录
mkdir -p ~/ledger && cp ~/storage/downloads/ledger.html ~/ledger/index.html
cd ~/ledger && python -m http.server 8888
```

Chrome 打开 `http://localhost:8888` → 菜单 → **添加到主屏幕**。之后每次使用前在 Termux 里重跑最后一行(或参照 [部署-Termux.md](部署-Termux.md) 的 Termux:Boot 一节配自启)。

> 实机待确认:`content://` 禁存储、`file:///sdcard` 可存储是 Chrome 安卓的已知行为;本仓库以「禁用 localStorage」模拟验证了降级路径(页面可用 + 提示条),真机行为如有出入请回报。

## 无后端的固有边界(诚实说明)

- **真实 OCR / 真实 AI 问答做不到**:视觉大模型与 LLM 需要 API Key,而 Key 只能放服务端(放进网页会被任何访问者拿走)。单机版 OCR 为固定样例、AI 问答为本地规则计算;要用真实识别请部署真实应用(见 [部署.md](部署.md))。
- **无跨设备同步**:数据在当前浏览器的 localStorage;换浏览器/清缓存即另一份数据。可用「导出 CSV」随时备份。
- **认证为本地模拟**(明文存本地,防误入不防攻击);真实应用为 scrypt + HttpOnly 会话 + proxy 中央守卫(ADR 0012)。
- 中英切换为单机版特性(真实应用暂无 i18n);中文为源语言,EN 词典缺词回退中文。基金详情暂无走势图(真实应用有 SVG 走势)。

- 真实应用新增用户可见功能后,**同步更新本单机版**(改 `docs/demo/记账本演示.html`,再重新发布到上面同一 Artifact 链接)并刷新本文件的功能表。
- **按键位置原则**(2026-07 重设计):底部导航 5 槽对称(流水/基金/**＋居中**/分析/我的),高频「记一笔」在拇指最优区;页面级操作**下沉为卡片下方等宽按钮行**(如基金页 OCR/手动记),不塞头部右上角;"添加"类动作用**全宽虚线按钮**置于列表前;分段切换随所属表单居中,不放角落;首页次要动作(导入)用 ghost 降视觉权重。
- **设计令牌**(2026-07 简化版重构):细描边扁平卡片(`--line` 1px,无投影,弹层除外);主色浅 `#2f7a68`/深 `#5cb39d`;语义色仅用于提醒(琥珀=到期、红=超支/异常/删除);金额统一 `tabular-nums`,大数 30px/750;二级页统一「‹ 标题 + 右侧动作」头部;提醒一律单行条(首项 + 剩余计数),不占大块。
- **列表内操作按钮带对象名 aria-label**(如 `改名餐饮`/`删除宠物`),冒烟与测试选择器禁用 first()/last() 盲选(见 lessons)。
- 改动后必跑冒烟脚本(注册→三类提醒条→编辑面板→记一笔→OCR→基金→分析(含异常)→预算→周期支出→净资产→月报→问答→分类管理→导出→登出)且浅/深两主题截图目检。
- localStorage 结构变更须在 `load()` 里做**旧数据迁移**(如 2026-07 分类改为可管理状态时补 `cats/nextCat` 字段),不清用户数据。
